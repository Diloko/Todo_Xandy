# To-Do API

Projeto CRUD de tarefas desenvolvido com Spring Boot e PostgreSQL.

## Tecnologias

- Java 17+
- Spring Boot
- Spring Data JPA
- PostgreSQL
- JUnit 5

## Funcionalidades

- Criar tarefa
- Listar tarefas
- Buscar tarefa por ID
- Atualizar tarefa
- Excluir tarefa

## Executar

mvn spring-boot:run

## Testes

mvn test
